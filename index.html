[ 01 :: CONCEITO PRINCIPAL ]
==============================================================================

O objetivo de um jogador F2P não é buildar os heróis mais fortes possíveis.

O objetivo é criar uma conta capaz de: 

    • Fazer vários conteúdos.
    • Gastar recursos com eficiência.
    • Evitar investimentos em heróis muito nichados.
    • Manter uma progressão estável.

[ 02 :: GERAL ]
==============================================================================

Todos os heróis seguem a mesma base de evolução.

O custo para evoluir um personagem é igual para todos. 

    • Chaser Nv.25 → 600 Cubos + ≈900 Essências + ≈70kk de Ouro
    • Selo da Alma Nv.15 → 3000 Cubos + ≈2500 Essências + ≈100kk de Ouro
    • Descendência Nv.10 → 38k de Cristais + 6k de Essências + 50kk de Ouro

Portanto:

O que diferencia um herói bom de um herói ruim não é o quão caro ele é.

Mas: 

    • Quanto conteúdo ele faz pelo investimento que exige.
    • Quanto "tempo ele economiza" pelos personagens que substitui.
┌─ OBSERVAÇÃO ───────────────────────────────────────────────────────────────┐
│                                                                            │
│ Nem todos os personagens possuem os mesmos timings.                        │
│                                                                            │
│ Alguns funcionam muito bem no Selo da Alma Nv.15.                          │
│ Outros precisam de Descendência Nv.3 → Nv.5 → Nv.10.                       │
│                                                                            │
│     → "Esse herói funciona no estágio atual?"                              │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

Grand Chase Mobile possui três categorias principais de personagens. 

[SR] SUPER RARO
──────────────────────────────────────────────────────────────────────

──────────────────────────────────────────────────────

Versão Alternativa do Boneco.

Requisitos:

    ├── Ter Herói [SR] Chaser Nv.20
    ├── Completar Missão de Troca de Classe
    └── Você NÃO perde o personagem base.

A versão [SR] e a versão [T] são unidades separadas.

Portanto, não compartilham:

    ├── Skins
    ├── Materiais
    ├── Equipamentos exclusivos
    └── Progressão

[ 04 :: INVESTIMENTO ]
==============================================================================

Investir em vários personagens não impede a progressão.

O problema é espalhar recursos demais sem construir uma base sólida.

A recomendação geral é evoluir um personagem de cada vez. 

POR QUÊ?

Porque cada recurso possui um gargalo diferente:

    • Cubos.
    • Essências.
    • Cristais.
    • Equipamentos.
────────────────────────────────────────────────────────────────────────────────
                              ESTRATÉGIA
────────────────────────────────────────────────────────────────────────────────
Criar uma base de times:

    Time Vida
    +
    Time Equilíbrio
    +
    Time Destruição

Com Heróis Selo da Alma Nv.15.

                         ↓

Buscar o Nv. mínimo de Descendência necessário
nos personagens que dependem dela.

                         ↓

Ideal:

    2 Times de cada atributo.

O jogo constantemente exige: 

    • Diferentes atributos.
      Verde → Azul → Vermelho → Repete.

    • Diferentes danos.
      Físico / Mágico.

    • Diferentes funções.
      Sem Guardião / Sem Atirador
      ↔
      Sem Mago / Sem Hab. Especial...

Não fique dependendo de um único herói ou de um único time para fazer tudo.

[ 05 :: FORMAÇÃO DE EQUIPES ]
==============================================================================

Uma equipe normalmente possui:

4 Heróis — máximo possível. 

Preferencialmente:

    • Do mesmo atributo.
    • Com boa sinergia.
    • Com funções complementares.
────────────────────────────────────────────────────────────────────────────────
                                FUNÇÕES
────────────────────────────────────────────────────────────────────────────────
GUARDIÃO
    → Escudo de Carne

GUERREIRO
    → Debuff de inimigos
    → Buff de aliados

DPS
    → Mago / Atirador
    → Dá dano.

SACERDOTE
    → Gera SP acima de tudo.

    Qualquer coisa além disso é lucro.

    Se ele faz tudo, mas não gera SP...
    Péssimo Sacerdote.
────────────────────────────────────────────────────────────────────────────────
                                SCORING
────────────────────────────────────────────────────────────────────────────────
OBJETIVO

    Causar mais dano em menos tempo.


FORMAÇÃO

    GUERREIRO → DPS → DPS → SACERDOTE
────────────────────────────────────────────────────────────────────────────────
                               PROGRESSÃO
────────────────────────────────────────────────────────────────────────────────
OBJETIVO

    Terminar / Sobreviver à fase.


FORMAÇÃO

    GUARDIÃO → GUERREIRO → DPS → SACERDOTE
................................................................

A diferença:

    SCORE
    → "Quanto dano eu consigo causar?"

    PROGRESSÃO
    → "Eu consigo tankar essa porra?"

[ 07 :: FORNALHA INFERNAL ]
==============================================================================

A Fornalha Infernal funciona de maneira diferente da maioria dos conteúdos.

Aqui, o fator mais importante além da pontuação obtida é o seu Battle Power (BP).

Quanto maior o BP da conta, melhores serão as recompensas. 

                              TIERS

    1,00 M ─────────► 1,99 M    = ESCUDEIRO

    2,00 M ─────────► 2,99 M    = CAVALEIRO

    3,00 M ─────────► 3,99 M    = PALADINO

    4,00 M+ ────────► ???       = GENERAL
ÚLTIMA COLOCAÇÃO

    ESCUDEIRO
        ≈ 3.000 Gemas


    GENERAL
        ≈ 25.000 Gemas

A diferença é enorme.

Por isso fortalecer a conta vale muito mais do que apenas melhorar personagens.
