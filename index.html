Maximize sua conta.

O objetivo de uma conta não é criar o herói mais forte possível.

O objetivo é criar uma conta capaz de: 


• Fazer vários conteúdos.

• Gastar recursos com eficiência.

• Evitar investimentos ruins.

• Ter progressão constante.
