[ CONCEITO PRINCIPAL ]
==============================================================================


O objetivo de um jogador F2P não é buildar os heróis mais fortes possíveis.

O objetivo é criar uma conta capaz de:
    • Fazer vários conteúdos.
    • Gastar recursos com eficiência.
    • Evitar investimentos em heróis muito nichados.
    • Manter uma progressão estável.

A pergunta errada:
"Qual é o heróis mais valioso do jogo?"


A pergunta correta:
"Qual herói mais valioso nesse momento?"



==============================================================================
[ GERAL ]
==============================================================================


Todos os heróis seguem a mesma base de evolução.

O custo para evoluir um personagem é igual para todos.

    • Chaser Nv.25 -> 600 Cubos + ≈900 Essências + ≈70kk de Ouro
    • Selo da Alma Nv.15 -> 3000 Cubos + ≈2500 Essências + ≈100kk de Ouro
    • Descendência Nv.10 -> 38k de Cristais + 6k de Essências + 50kk de Ouro 

Portanto:
    O que diferencia um herói bom de um herói ruim não é o quão caro ele é.

    Mas,

    • Quanto conteúdo ele faz pelo investimento que ele exige.
    • Quanto "tempo ele economiza" pelos "personagens que ele substitui".


OBSERVAÇÃO::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::
::
:: Nem todos os personagens tem os mesmos timings.
:: Alguns funcionam muito bem no: Selo da Alma Nv.15;
:: Outros precisam de: Descendência Nv.3 -> Nv. 5 -> Nv. 10; pra funcionar
::
:: -> "Esse herói funciona no estágio atual?"
::
::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::


Um personagem pode ser muito META e ainda assim, ter um valor baixo pra sua conta 

e.g. Herói A: Gera números absurdos, mas:
Precisa de um set específico -> Precisa de comp específica -> Faz pouco conteúdo.

e.g. Herói B: Números okay, ainda não ganhou o novo sistema "Holy-Motherfucking-Ego".
Funciona em vários modos -> Funciona com vários times -> Exige menos recursos 

Se tu não for um Ranker:
i.e. Herói B geralmente tem mais valor.

[ INVESTIMENTO ]
==============================================================================


Investir em vários personagens não impede a progressão.

O problema é espalhar recursos demais sem construir uma base sólida.

A recomendação geral é evoluir um personagem de cada vez.

Por quê?

Porque cada recurso tem um gargalo diferente:
    • Cubos.
    • Essências.
    • Cristais.
    • Equipamentos.


─────────────────────────────────────────────────────────────
				ESTRATÉGIA
─────────────────────────────────────────────────────────────


Criar uma base de times:
Time Vida + Time Equilíbrio + Time Destruição;
Com Heróis Selo da Alma Nv.15.	
		↓
Buscar Nv. Mínimo de Descendência necessária,
nos personagens que dependem da descendência.
		↓
Ideal é montar:
2 Times de cada atributo.

O motivo? O jogo constantemente exige:

    • Diferentes atributos pra diferentes conteúdos (Verde -> Azul -> Vermelho -> Repete).
    • Diferentes danos (Físico / Mágico).
    • Diferentes funções (Sem Guardião / Sem Atirador <-> Sem Mago / Sem Hab. Especial...)

Não fique dependendo de um único herói, ou de um único time, para fazer tudo.

==============================================================================
[ FORNALHA INFERNAL ]
==============================================================================


A Fornalha Infernal funciona de maneira diferente da maioria dos conteúdos.

Aqui, o fator mais importante além da pontuação obtida é o seu Battle Power (BP).

Quanto maior o BP da conta, melhores serão as recompensas.


			TIERS

    1,00 M ─────────► 1,99 M = Escudeiro

    2,00 M ─────────► 2,99 M  = Cavaleiro

    3,00 M ─────────► 3,99 M  = Paladino

    4,00 M+ ────────►   ???   = General


    Última colocação (Escudeiro)
        ≈ 3.000 Gemas

    Última colocação (General)
        ≈ 25.000 Gemas


A diferença é enorme.

Por isso fortalecer a conta vale muito mais do que apenas melhorar personagens.
